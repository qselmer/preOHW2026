# Actividad final — Mini proyecto (viernes)

**Objetivo:** integrar carga de datos, exploración básica, visualización, función propia documentada y conclusiones.

## Estructura
```text
03_proyecto_final/
├── README.md
├── datos/
│   └── datos_ejemplo.csv
```

## Ejecución
Abrir `notebook.ipynb` en JupyterLab. Requiere Python, `pandas` y `matplotlib` (`pip install pandas matplotlib`). Ejecutar todas las celdas y guardar. El notebook exporta `figuras/variacion_mensual.png`. Incluir la imagen en el commit final si se desea conservarla en GitHub.

**Nota:** el CSV es un conjunto **simulado y didáctico**, copiado de la primera actividad. No se ha proporcionado aún el conjunto oficial de la organización; antes de presentar esta entrega como proyecto definitivo, reemplazar los datos, ajustar análisis e interpretar los resultados propios.

**Commit sugerido:** `git add 03_proyecto_final && git commit -m "Entrega final: mini proyecto de analisis" && git push`.
