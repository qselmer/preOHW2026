# Entrega 3 — Viernes: mini proyecto de análisis
**Objetivo:** aplicar en un análisis breve las competencias adquiridas.

## Requisitos
- Usar el conjunto de datos proporcionado por la organización, cuando se distribuya.
- Cargar datos con ruta relativa (`datos/...`).
- Realizar exploración básica: estructura, tipos, datos faltantes y estadísticos adecuados.
- Incluir al menos una visualización pertinente.
- Definir y utilizar una función propia, con documentación.
- Redactar conclusiones breves y sustentadas por los resultados.
- Guardar notebook ejecutado, figuras en `figuras/` si se exportan y commit final.

**Evidencia:** enlace/SHA del commit final. Las correcciones posteriores deben quedar en commits nuevos.
